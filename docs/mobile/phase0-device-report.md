## 計測キットの使い方

1. 試験用のディレクトリと XDG_CONFIG_HOME、XDG_STATE_HOME、XDG_DATA_HOME を用意し、通常利用の設定から分離して起動します。
2. このリポジトリの `web` で `npx vite --host 0.0.0.0 --port 5173` を実行します。LAN または Tailscale 内の試験中だけ配信し、終了後に止めます。
3. `/spike/viewport-probe.html` で表示を計測します。interactive-widget の比較は切替ボタンで再読み込みして行います。リサイズ時の履歴を「JSON を保存」で取得します。
4. 通常の試験画面は `/p/<id>/?inputlog=1` で入力ログを有効にします。無効化は `?inputlog=0` です。設定は同じオリジンに残ります。
5. `/spike/block-edit-probe.html` で限定ブロック編集を比較します。ここでは入力ログが常に有効です。✎、完了、元に戻すの順に確認します。通常画面への保存は行いません。
6. 各ケースの開始時に入力ログをクリアし、終了時に「JSON をダウンロード」で保存します。`device-logs/YYYYMMDD-<機種>-<ID>.json` に置き、表からファイル名を参照します。

入力ログはメモリー上に最大3000件を保持します。再読み込み前にダウンロードしてください。入力欄の全文や貼り付けの全文は保存しませんが、IME確認用の `data` はイベントごとに最大20文字残ります。HTTPではダウンロードを使えます。コピーは既存のフォールバックを使います。

ブロック編集の「元に戻す」は完了した範囲変更を1回戻します。編集中のネイティブUndoは textarea の動作を確認します。試験用の60行には見出し、段落、リスト、コードブロックがあります。
