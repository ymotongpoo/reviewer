# モバイル性能と行高の判定

## C9: タッチ時の行高

2026-10-04、C2のS-09測定値として今回の作業指示で指定されたB/A比 **0.996**、スクロール中の最大longtask **0ms** を根拠に、`adopt` と判定しました。B/A比が1.5以下、最大longtaskが200ms以下という基準を満たすため、タッチ時の行に `min-height: 44px` を設定しています。

S-09は412×915、CPU 4倍制限、3000行の `big.md` で、A（従来CSS）とB（行高44px、編集とコメントの印を常時表示）を比較する測定です。表示時間は遷移からL3000のDOM出現まで、スクロールは10段階のプログラム操作です。0msは50ms以上のlongtaskが観測されなかったことを表します。

既存の [C2レポート](phase0-spike-report.md#s-09-3000行の性能) には別の記録としてA中央値635.9ms、B中央値656.7ms、比1.033、最大longtask 0msが残っています。今回指定の0.996に対応する各回の生データは引き継ぎに含まれていません。既存記録を上書きせず、今回指定の値と区別して記録します。いずれの比率でも判定は `adopt` です。C9でS-09の再計測はしていません。実装後の性能比較はC14の対象です。

実機ゲートは未実施です。Androidの指スクロール、GPU、発熱、Gboard、選択ハンドルの検証を代替する測定ではありません。編集方式 `undecided`（既存インライン編集を維持）、hidden時のSSE切断 `no`、interactive-widget `default` の既定判定を維持しています。

## C14の測定方法

実機ゲートは未実施です。以下は実装後のHeadless Chromiumの測定であり、実機の代替ではありません。

`cd web && npm run e2e:perf` で、desktop 1440×900とmobile-412 412×915を測定します。既存の `desktop` プロジェクトに性能試験は追加していません。変更範囲を `package.json` の `e2e:perf` に限るため、このスクリプトは一時ディレクトリに専用のPlaywright設定を生成し、共通設定のglobalSetup、globalTeardown、XDG隔離を引き継ぎます。設定ファイルは試験終了時に削除します。`npm run e2e:perf -- --output=<path>` で出力先を指定できます。

両プロファイルでCPUを4倍に制限し、3000行の `big.md` を5回測ります。各回は新しいブラウザコンテキストを使います。S-09と同じく、ハッシュルート遷移からL3000のDOM出現までを描画時間とし、トークンの描画後に10段階、100ms間隔でスクロールします。scrollHeightと各段階のscrollTopも保存し、実際にスクロールしたことを確認します。

longtaskはスクロール中に記録した50ms以上のタスクです。0msは該当タスクを観測しなかったことを表します。各回の最大値の中央値と、全5回の最大値を区別して記録します。最初のファイル読み込みにかかったlongtaskは、このスクロール用の値には含みません。

入力はL3の末尾へ1文字ずつ10回、各回の計測終了を待って送ります。`input` イベントのtimestampからリスナー実行までの時間と、リスナーから2回目のrequestAnimationFrameまでの時間を記録します。後者は編集処理とフレーム待ちを含む代理指標であり、INP、実際の画面描画完了、タッチから表示までの遅延ではありません。本文に10文字が入ったことも検証します。

横溢れはdocument幅とinnerWidth、mainのclientWidthとscrollWidthで記録します。タップ領域はヘッダー、ファイル操作、3000行の鉛筆と行番号から寸法を採取します。mobileでは43.5px未満を失敗にします。desktopの小さい操作は比較データとして記録し、44pxを要求しません。全状態の操作領域と危険操作の間隔は `mobile/tap-targets.e2e.ts` が別途検証します。

C1時点の性能の生データは確認できませんでした。比較欄には、出典を区別してC2の変更前S-09記録を載せます。C9の採用判定に使った0.996という値を今回の測定値として扱いません。測定日時や実装、ホスト負荷が異なるため、C2との比率だけで性能退行を断定できません。

最終計測では `E2E_ROOT=/tmp/reviewer-c14-perf/reviewer-e2e E2E_PORT=17814 E2E_SKIP_BUILD=1` を指定しました。試験サーバーの設定とデータはこの一時ディレクトリ内に隔離し、既に成功した本番ビルドを使っています。初回の中断後に試験サーバーのポート競合が発生したため、測定専用のrootとportで最初から測り直した結果だけを掲載しています。
