# モバイル性能と行高の判定

## C9: タッチ時の行高

2026-10-04、C2のS-09測定値として今回の作業指示で指定されたB/A比 **0.996**、スクロール中の最大longtask **0ms** を根拠に、`adopt` と判定しました。B/A比が1.5以下、最大longtaskが200ms以下という基準を満たすため、タッチ時の行に `min-height: 44px` を設定しています。

S-09は412×915、CPU 4倍制限、3000行の `big.md` で、A（従来CSS）とB（行高44px、編集とコメントの印を常時表示）を比較する測定です。表示時間は遷移からL3000のDOM出現まで、スクロールは10段階のプログラム操作です。0msは50ms以上のlongtaskが観測されなかったことを表します。

既存の [C2レポート](phase0-spike-report.md#s-09-3000行の性能) には別の記録としてA中央値635.9ms、B中央値656.7ms、比1.033、最大longtask 0msが残っています。今回指定の0.996に対応する各回の生データは引き継ぎに含まれていません。既存記録を上書きせず、今回指定の値と区別して記録します。いずれの比率でも判定は `adopt` です。C9でS-09の再計測はしていません。実装後の性能比較はC14の対象です。

実機ゲートは未実施です。Androidの指スクロール、GPU、発熱、Gboard、選択ハンドルの検証を代替する測定ではありません。編集方式 `undecided`（既存インライン編集を維持）、hidden時のSSE切断 `no`、interactive-widget `default` の既定判定を維持しています。
